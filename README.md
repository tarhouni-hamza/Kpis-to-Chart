# Python KPI Report & Chart Generator 📊

A simple, beginner-friendly Python script that takes a dictionary of Key Performance Indicators (KPIs) and chart data, automatically generates a matplotlib bar chart, and compiles everything into a clean PDF executive report using ReportLab.

---

## 🚀 Features
- **Automated Chart Generation:** Converts raw dictionary data into a clean bar chart image.
- **Dynamic Table Builder:** Automatically formats your KPI metrics into a structured PDF table.
- **Auto-Cleanup:** Deletes temporary chart images after the PDF is built.
